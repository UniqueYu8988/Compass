# 日记

这里保存每天真实发生的事、当时的感受和一时的想法。内容可以很小，也不需要证明有长期价值。

## 怎样使用

- 想写时再写，不要求连续打卡，也不补欠下的日期。
- 可以自己记录，也可以在聊天中讲述后请Compass代为整理。
- 当对话中自然出现能够较可靠判断为当天真实发生的经历、行动、感受或小成果时，Compass可以静默追加，不要求专门发出记录指令，也不为此单独回复“已记录”。
- 日记是生活原稿，不是稳定事实、人格结论或任务清单。
- AI启动Compass时默认不读取本目录。追加记录时可以只查看当天文件以避免重复；只有你明确要求回看某天、复盘一段时期，或当前问题必须核对原始经历时，才读取其他日期。
- 不把计划、假设、玩笑或AI推断写成已经发生的事实，不保存密码、验证码和令牌。日期或事实存在重要歧义时，暂不自动记录。
- 你可以随时暂停当天的自动记录，或要求删除、修改任何内容。
- 日记中的重要变化不会自动改写其他文件。经过确认后，近期状态写入`02_此刻`，重要选择写入`04_选择`，阶段规律写入`05_回望`，长期认识才写入`01_关于我/认识我.md`。

日记按`年份/月份/日期.md`保存，例如`2026/07/2026-07-17.md`。写法保持自然，不要求套用固定模板。

## 隐私提示

本仓库默认通过`.gitignore`忽略这里的个人日记，只保留这份说明。提交或推送前仍建议运行`git status`，确认没有意外加入私人文件。
