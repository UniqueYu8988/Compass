# Compass

> 把对自己的理解留在自己手里，让下一次对话不必从头开始。

Compass是一组简洁、可持续更新的Markdown文档。它让AI逐渐理解你走过的路、此刻的位置、想去的方向和一路作出的选择，并把这些认识保存在你自己的文件夹中。

它不是替你规划全部人生的自动驾驶，也不是需要一次填完的人生问卷。你只需要从眼下最想解决的事情开始，Compass会在真实交流和行动中慢慢长出来。

## 它解决什么问题

长期使用AI时，我们经常遇到这些情况：

- 换一个对话，就要重新解释自己的背景；
- 重要思考散落在不同平台和聊天记录中；
- 计划停留在对话里，过一段时间便失去上下文；
- AI记住了某次情绪，却没有理解一个正在变化的人；
- 一份越来越长的聊天记录，反而让当前重点变得模糊。

Compass把相对稳定的背景、近期状态、方向、选择和回望分开保存。对话可以结束，模型可以更换，但这些文件仍然可以继续使用、修正和带走。

## 快速开始

### 1. 获取文件

如果只是想建立自己的Compass，推荐下载仓库的ZIP，解压到一个只属于自己的文件夹。这样私人记录不会与公开模板的Git历史混在一起。

也可以在GitHub中使用`Use this template`创建一个**私有仓库**，或者仅在参与项目开发时使用Git：

```bash
git clone https://github.com/UniqueYu8988/Compass.git
```

保留`AGENTS.md`文件名，以便Codex自动读取协作规则。不要把填写了个人内容的文件夹推送到公开仓库。

### 2. 在Codex中打开

新建一个任务，将这个文件夹设为项目目录。

### 3. 发送第一句话

```text
请阅读本项目根目录的《初次见面.md》，按照其中的要求开始认识我，并和我一起建立Compass。
```

第一次交流不需要准备履历。说出你为什么现在想建立Compass，以及眼下最希望得到什么帮助，就足够开始。

## 第一次会发生什么

Compass要求AI：

1. 先理解这些文件各自负责什么；
2. 第一轮最多询问三个必要问题；
3. 不要求你一次讲完人生，也不立即生成宏大计划；
4. 将已经确认的内容写入`认识我`、`此刻`和`方向`；
5. 把初步理解交还给你检查，而不是悄悄固化判断；
6. 最后找到一个值得做、足够小的下一步。

### [认识我](01_关于我/认识我.md)

保存相对稳定的背景、价值、优势、困难和有效协作方式。它不是最终人格定义，也不应被一次情绪或单次事件随意改写。

### [来时的路](01_关于我/来时的路.md)

连接重要经历、旧文档和过去判断。历史可以解释今天，但不会自动覆盖今天。

### [此刻](02_此刻/此刻.md)

记录最近真实发生的事情、当前资源、限制和下一步。它经常变化，并且优先于旧计划。

### [方向](03_方向/方向.md)

记录当前主线、接下来一段路、长期可能性和主动暂缓的事情。方向可以随着新证据调整。

### [选择记录](04_选择/选择记录.md)

保存重要选择当时的事实、理由、不确定性和后来结果，让改变决定也有迹可循。

### [回望](05_回望/回望.md)

从一周、一段经历或一个阶段中发现真正有效和无效的条件，而不是给自己打分。

### [旅程](06_旅程/README.md)

学习、工作、关系、健康、创作或一个持续多年的项目，都可以在真正需要长期跟踪时自然加入。

### [日记](07_日记/README.md)

保存每天真实发生的小事、感受和阶段成果。聊天中能可靠判断为当天经历的内容，可以由AI静默追加；同一天的新内容可以继续补入，并随当天真正重要的时刻更新标题。它默认不会读取过去的日记，也不会把日记直接当成稳定的人格结论。

## 日常怎样使用

不需要固定口令，可以像普通对话一样表达：

- “我最近有些混乱，帮我看看真正的问题是什么。”
- “我在两个选择之间犹豫。”
- “我卡住了，帮我把下一步缩小。”
- “今天发生的事情值得留下来。”
- “这段别记”或“今天不要自动记录。”
- “回看最近一段时间，有什么规律正在出现？”
- “检查我的行动有没有偏离现在最重要的方向。”

AI会根据[AGENTS.md](AGENTS.md)判断什么值得更新。你可以随时查看、修改或推翻它的理解。

## 为什么不把所有内容放在一个文件里

人的背景、状态和方向变化速度不同：

- 背景相对稳定，不应该每天重写；
- 此刻变化很快，需要及时更新；
- 选择需要保留当时依据；
- 原始经历可以完整保存，但不必每次全部进入上下文。

分开保存不是为了把人生变成数据库，而是为了让AI知道什么时候应该相信最新状态，什么时候应该回看历史。

## 带到其他AI

Compass使用普通Markdown文件，不依赖专有数据库。临时向其他AI咨询时，通常只需提供：

- `01_关于我/认识我.md`
- `02_此刻/此刻.md`
- 与问题相关的旅程文件
- 这一次具体想解决的问题

其他工具不一定会像Codex一样自动读取`AGENTS.md`，可以同时附上该文件或明确要求AI先阅读它。

## 在Obsidian中阅读和修改

Compass本身就是Markdown文件夹，可以直接作为一个Obsidian笔记库打开，不需要复制、迁移或建立同步脚本：

1. 在Obsidian中选择“打开本地仓库”；
2. 选择你的Compass文件夹；
3. 之后仍让Codex使用同一个文件夹。

这样你和AI读写的是同一份内容。Obsidian只是阅读与手动修改的界面，不会改变Compass的目录结构或协作方式。

## 使用原则

- 当前明确表达高于旧记录；
- 事实、自述、推断和待验证想法应当区分；
- 单次事件不应轻易固化成稳定人格判断；
- 重要进展不要只留在聊天中；
- 文件写给AI，也写给未来回看的自己；
- Compass应该帮助现实行动，而不是成为新的整理负担。

## 常见问题

### 需要先填写所有文档吗？

不需要。保留空白直接开始对话，AI会根据交流逐步填写。

### 可以增加或删除目录吗？

可以。Compass提供的是起点而不是固定格式。真正反复出现、需要长期跟踪的主题再加入`06_旅程`，不必为了完整而制造空目录。

### 它会自动知道我的一切吗？

不会。Compass只是让理解有可靠的落脚点。AI仍然可能误解，所以重要认识需要由你确认，也应当允许未来证据修正。

### 可以在不同平台之间使用吗？

可以。Markdown文件可以单独上传或复制给其他AI，但不同平台读取本地目录和自动执行规则的能力不同。

### 我的日记会被提交到GitHub吗？

仓库的`.gitignore`默认忽略`07_日记`中的个人日记，只保留使用说明。它能降低误提交风险，但不能替代提交前检查：如果你修改了忽略规则、强制添加文件或主动粘贴私人内容，仍应在推送前运行`git status`确认。
